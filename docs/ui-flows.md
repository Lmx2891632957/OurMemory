# 页面结构与交互设计

> 版本：v0.1（2026-11-03）· 配套 `docs/prd.md`
> 线框是**结构示意**，不是最终视觉；颜色/圆角/动效在实现时按 Material 3 主题走。

## 1. 信息架构

```
启动
├── 隐私合规页（首次）
└── 信息流（首页）
    ├── 记录详情
    │   └── 删除（二次确认）
    ├── 拍照 → 发布
    ├── 相册（P1）
    ├── 地图回忆（P1）
    └── 我的 / 设置（P2）
```

导航形态：**底部 3 个 Tab（时间线 / 相册 / 地图）+ 记录用 FAB**。
理由：情侣 App 的主线是「看回忆」，Tab 比抽屉更适合单手。

## 2. 核心流程

### 2.1 记录一条（主流程）

```
[信息流] --点 FAB--> [相机] --快门--> [发布页] --发布--> [信息流(滚动到顶)]
                        └--关闭--> [信息流]        └--返回--> 二次确认「放弃这条记录？」
```

- 相机页只保留：关闭、快门、前后摄切换。
- 发布页必须**先显示照片**（本地立刻可见），地点异步补上。
- 发布成功后回首页并滚到顶部，不做成功弹窗（避免打断）。

### 2.2 回看一条

```
[信息流] --点卡片--> [详情] --左右滑--> 上一张/下一张照片
                      ├--点地点--> 地图定位到该点（只读）
                      └--右上角--> 删除（二次确认，无编辑）
```

### 2.3 关于"改错"

本期**不做编辑**。发错了就删除重发（照片可以从相册重新选，P1 提供）。

理由：编辑会让「草稿/已发布/同步状态」三套状态互相纠缠，而情侣记录场景里写错的概率远低于"记一条新的"。等真有人抱怨再考虑。

### 3.1 信息流（首页）

```

│ 我们的记录              [相册]│  ← 顶栏，右侧可放次要入口
├─────────────────────────────┤

│ ┌─────────────────────────┐ │
│ │ ◯我  我们        10:24 ⋮│ │  ← 头像/作者/时间/更多
│ │ 📍 华中科技大学韵苑     │ │  ← 地点（可点，进地图）
│ │ ┌─────┬─────┬─────┐     │ │  ← 1/2/3+ 张自适应
```

空态：居中「还没有记录 / 点右下角 + 拍下第一张照片」。

## 4. 状态矩阵

| 页面 | 空 | 加载 | 错误 | 权限拒绝 |
|---|---|---|---|---|
| 信息流 | 引导文案 + FAB | 骨架屏（>300ms 才显示） | 顶部重试条 | — |
| 相机 | — | 取景黑屏 + 转圈 | 文案 + 重试 | 说明 + 去设置 |
| 发布页 | — | 照片本地即时显示 | Snackbar + 保留草稿 | 地点可手填 |
| 详情 | — | 图片占位 | Snackbar | — |
| 相册 | 空网格 + 引导 | 缩略图占位 | 重试 | — |
| 地图 | 默认城市 | 瓦片加载 | 坐标兜底 | 手动选点 |

## 5. 交互规范

- **返回**：发布页返回必须二次确认（已有）；详情页直接返回。
- **删除**：二次确认，按钮用红色文字，不用红色填充（降低误触）。
- **反馈**：轻量结果用 Snackbar（如"已发布"），错误用 Snackbar + 可重试动作。
- **加载**：超过 300ms 才显示 loading，避免闪烁。
- **图片**：统一 4:3 裁切预览，详情页可看原图。

## 6. 视觉基调（实现参考）

- 风格：温暖、治愈、可爱、有生活气息；具体色值/字号/组件见 [设计规范（Design Tokens）](design-tokens.md)。
- 间距：8dp 网格；页面左右边距 20dp；卡片圆角 20dp；卡片间距 16dp。
- 字号：页面标题 22sp / 卡片标题 16sp / 正文 15sp / 辅助 12sp。
- 颜色：固定暖色品牌色（暖杏 + 燕麦奶白 + 深可可文字），**关闭 Android 12+ 动态取色**。
- 深色模式：全部页面支持，使用暖褐夜色版，不使用纯黑。
- 卡片：白底大圆角 + 柔和投影，不用硬边框。
